# 🇵🇸 Gaza Pulse - Humanitarian Offline Network

> **Connecting Communities & Resources During Network Blackouts**

**Gaza Pulse** is an innovative Android application built to empower local communities during crisis situations, emergencies, and internet blackouts. Designed as an offline-first humanitarian platform, it enables users to track vital life-support resources, exchange essential supplies through a peer-to-peer barter network, and share crucial updates without relying on active internet connectivity.

---

## ✨ Highlights & Core Features

* 💧 **Vital Resource Mapping:** Locate nearby clean water distribution points and community power charging stations in real time.
* 🔄 **Offline Barter Network:** Facilitate peer-to-peer exchanges to trade food, medical supplies, and essential goods directly.
* 📢 **Community Feed:** Share emergency announcements, safety updates, and humanitarian requests locally.
* 🔐 **Account & Identity Management:** Complete authentication flow with login, registration, password recovery, and customizable user profiles.
* 📱 **Seamless Multi-Screen Architecture:** Engineered with 7 dedicated Android activity screens ensuring an intuitive user interface.

---

## 🛠️ Tech Stack & Implementation

* **Programming Language:** Java
* **UI Layouts:** XML (`ConstraintLayout`, `CardView`, `ScrollView`, `LinearLayout`)
* **Development Environment:** Android Studio
* **Target OS:** Android (Min SDK: API 21+ / Android 5.0 Lollipop)
